module 03 — featured build

Movie Review Analysis

Sentiment analysis system for movie reviews
Python for Data Science · Academic project, 2025-26

A command-line application that collects movie reviews, cleans and processes the text, and uses a trained machine learning model to automatically classify each review as Positive or Negative. The system also lets users add, view, search, and delete reviews, and shows live statistics on overall sentiment distribution.

Python Pandas Scikit-learn TF-IDF Vectorization Multinomial Naive Bayes CSV data storage
